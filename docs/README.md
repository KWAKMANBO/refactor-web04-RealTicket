## 한눈에 보기

**전환**
- NestJS(TypeScript) → Spring Boot 3.5(Java 21, Spring MVC + 가상 스레드), JPA + Flyway, Redis + Lua
- API 33개의 경로·응답 형식을 유지해 **프런트엔드 수정 없이** 연결 (브라우저 E2E로 확인)
- Node 단일 스레드에 가려져 있던 경쟁 조건을 Lua로 원자 처리, 보안 문제 포함 **20건 이상 수정**
- 통합 테스트 **121개** (동시성 테스트, 실제 서버 SSE 연결 종료 테스트 포함)

**측정** (MacBook Air M3, 자원 제한 Docker, 3,000석, 4회 중앙값)

| 항목 | 결과 |
|---|---|
| 반정규화: DB가 읽는 행 | 3,000행 → **10행** |
| 반정규화: 조회 처리량 / p95 | **6.9배** / **76% 감소** |
| 원자적 처리 없는 동시 선점 (좌석 100개 × 100명) | DB 229~273건, Redis 1,022~6,027건 중복 예매 |
| Redis + Lua | **4회 모두 중복 예매 0건** |
| Redis + Lua vs DB 비관적 락: 처리량 / p95 | **4.2배** / **75% 감소** |
